# EveTradingbot documentation index

Last reconciled: **2026-09-04**

Start here when a supporting detail is not in the root control set. This index
classifies **every** maintained Markdown file, so a historical plan or a pasted review
prompt can never be mistaken for current status.

Rule: a Markdown file that is not listed here does not exist as far as an agent is
concerned. Adding, renaming, removing or reclassifying a file updates this table in the
same commit.

## Root control documents

| File | Purpose |
|---|---|
| [`README.md`](../README.md) | Setup, launch and orientation for a human |
| [`CHANGELOG.md`](../CHANGELOG.md) | Authoritative implemented inventory (searched, never read end to end) and the last build days under `Recent changes` |
| [`plan.md`](../plan.md) | Authoritative contract: architecture, locked decisions (§11), frozen verdict rules (§12.4, §13.6, §14.3), measured facts and deviations (§17), the open tracks. **2,961 lines — over the 1,200-line bound; see the note below** |
| [`CURRENT_CHECKPOINT.md`](../CURRENT_CHECKPOINT.md) | The "Active state at a glance" block, the active item, and the consolidated live-validation checklist |
| [`WISHLIST.md`](../WISHLIST.md) | Candidate ideas; never an implementation queue |
| [`CLAUDE.md`](../CLAUDE.md) / [`AGENTS.md`](../AGENTS.md) | Agent operating context; `AGENTS.md` is a generated byte-identical copy — edit `CLAUDE.md` only |
| [`VENDORED.md`](../VENDORED.md) | Provenance of code copied from TradingBotV3 (active reference) |

If a supporting document claims a different implementation status, the root
`CHANGELOG.md` / `plan.md` pair wins.

**On `plan.md`'s size.** It is in the mandatory read and is 2,961 lines against
JumpStarter's 1,200-line bound. It was **not** split on 2026-09-04: it is the contract
the whole repo cites by § number, and §11, §12.4, §13.6, §14.3 and §17 must stay where
they are cited. The bounded read in `CLAUDE.md` names the sections to read instead.
Archiving the completed tracks (§20–§22, the §23 phase log) into a dated file that keeps
their § numbers is the operator's decision, recorded as owed in `CURRENT_CHECKPOINT.md`.
